# Модуль тестирования памяти

BIST(Built In Self Test) - специальная аппаратура внутри чипа, которая позволяет тестировать
его уже после производства на наличие механических повреждений.

Модуль BIST, описанный в файле [BIST.v](BIST.v) тестирует однопортовую память([Memory.v](Memory.v))
на наличие таких ошибок, как SAF, TF, DRF. Именно эти ошибки чаще всего встречаются при изготовлении чипов.
